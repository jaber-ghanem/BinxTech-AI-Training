# Day 3

**What I learned:**

- **NumPy array creation** — using `np.linspace` to generate evenly spaced values and `reshape` to turn 1D arrays into 2D matrices.
- **Array indexing** — accessing elements by row and column, including negative indexing for reverse traversal.
- **Boolean masking** — filtering arrays by condition (`array[array > mean]`).
- **Broadcasting** — performing element-wise operations between arrays of different shapes without explicit loops.
