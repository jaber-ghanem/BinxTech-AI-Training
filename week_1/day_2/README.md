# Day 2

**What I learned:**

- **Custom data classes** for structured output — modeling function results with classes instead of plain dicts.
- **Python type hints** — annotating parameters (`list[float]`), return types (`-> CalculationOutput | None`), and union types (`int | None`).
- **List comprehensions** as a concise alternative to for-loops for filtering data.
- **Class design** — encapsulation with private attributes, instance methods, and separation of concerns.
- **Edge case handling** — returning `None` and guarding against empty input.
